# 《脉象》参赛版隐私与健康数据说明

更新日期：2026-07-31

## 数据处理范围

应用在用户主动开始测量后，通过 openvela `service.health` 获取测量期间的心率
采样值。应用在设备端将心率值换算为展示性统计指标，并生成传统脉象标签、六维
指标、五脏平衡趋势和生活方式参考。

当前版本：

- 不读取原始 PPG 波形；
- 不要求注册账号；
- 不包含网络请求、广告或第三方统计 SDK；
- 不向团队服务器或第三方上传健康数据；
- 不包含付费激活或商业验证服务。

## 本地保存

测量结果以 JSON 文件保存在应用内部文件目录，仅供本应用读取。代码当前按日期
保存记录，并将历史索引裁剪至最近 14 天。

应用进程可能在内存中缓存最近一次规则分析结果，以减少重复读盘和计算；进程结束
后该内存缓存消失。

## 删除数据

当前参赛版本尚未提供独立的“清除全部测量记录”按钮。用户可以通过系统应用管理
中的“清除应用数据”或卸载应用删除本地记录。提交前建议增加应用内清除入口，并
在真机上验证删除结果。

## 健康信息边界

心率换算得到的间期统计不等同于医疗设备提供的逐搏 RR 间期。“脉象、体质、
五脏平衡”等输出来自本地经验规则，仅用于传统文化科普和个人趋势观察，不构成
医疗诊断、治疗建议或疾病风险判断。如有身体不适或健康疑虑，请咨询具备资质的
医疗专业人员。

## 权限

应用申请健康数据权限用于主动测量期间读取心率，申请文件能力用于在设备本地保存
测量记录，申请亮屏能力用于降低测量期间因息屏导致计时或采样中断的风险。

本说明需要在获得官方仓库、最终包名、团队联系方式及上架渠道要求后再次复核。
