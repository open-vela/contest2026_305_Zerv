# 原创性与来源证据目录

本目录用于保存《脉象》参赛版可公开核验的来源、技术边界和开发过程说明。

原则：

- 只记录真实存在且可以核验的事实；
- 不回填、不伪造早期记录；
- 未确认事项保留 `待团队确认`；
- AI 对话导出前必须删除密钥、个人隐私和商业服务端敏感信息；
- 同类产品存在不等于本项目侵权，但不得宣称品类首创。

当前文件：

- `timeline.md`：项目与相关产品时间线；
- `related-work.md`：已知同类产品及差异边界；
- `asset-register.csv`：素材和第三方内容登记；
- `ai-coding-log-index.md`：AI Coding 日志索引；
- `algorithm-notes.md`：真实数据链路、公式和限制；
- `submission-diff.md`：参赛版、商业版及专属仓差异。
- `zepp-ai-development-record.md`：Zepp OS 前置版本的 AI 辅助开发记录整理；
- `local-project-audit-2026-07-31.md`：提交官方仓库前的本地工程审查；
- `../PRIVACY.md`：健康数据处理和隐私说明。
