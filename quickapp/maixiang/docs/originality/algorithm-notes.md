# 数据链路与算法边界

## 真实数据链路

1. `service.health` 提供按时间到达的心率 BPM 样本；
2. 程序进行输入范围过滤；
3. 使用 `60000 / BPM` 得到“换算间期”；
4. 对心率序列和换算间期计算展示性波动统计；
5. 经验阈值把统计值映射为六维标签、传统脉象标签、体质文化标签和五脏关联分；
6. 结果写入设备本地文件并由页面展示。

## 明确限制

- 未读取原始 PPG 波形；
- 换算间期不是逐搏传感器测得的 RR；
- 从低频 BPM 样本得到的 SDNN、频段近似和 E/I ratio 不具有临床 HRV 等价性；
- 十四脉、体质和五脏关联均为经验规则映射，没有临床验证；
- 输出仅用于传统文化科普、交互演示和个人趋势观察。

## 主要代码位置

| 模块 | 作用 |
|---|---|
| `src/pages/measurement/index.ux` | 健康服务订阅、测量状态和记录保存 |
| `src/utils/hrv_calc.js` | BPM 换算间期和展示性波动统计 |
| `src/utils/pulse_diagnosis.js` | 经验规则映射 |
| `src/utils/hrv_storage_manager.js` | 按日文件存储和历史裁剪 |
| `src/utils/storage.js` | `@system.file` JSON 持久化 |
